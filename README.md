## SmartLight: Object-Oriented Programming and Unit Testing

### Project Overview

This project demonstrates object-oriented programming
concepts through a simluated smart lighting system.

### Features

- Turn a simulated smart light on and off.
- Adjust brightness settings.
- Validate brightness values.
- Handle invalid inputs.
- Test program functionality using automated unit tests.

### Programming Concepts

- Python classes and objects
- Object-oriented programming
- Constructors and methods
- Conditional statements
- Exception handling
- Unit testing with Python's unittest framework

### Running the Program

Run the following command:

python main.py
